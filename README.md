# Switch / Ports

Русскоязычный каталог homebrew-портов и эмуляторов для Nintendo Switch.

**Сайт:** https://lonviser.github.io/switch-ports/

Поиск по названию, автору и платформе; фильтры по типу, исходной платформе, совместимости с FW 21+ и обновлениям за 7 дней. По умолчанию проекты отсортированы по популярности — числу звёзд соответствующего репозитория на GitHub. Карточки с версиями, датами, обложками, страницами авторов и обсуждениями. Локальное избранное, адаптивный интерфейс и ссылки с сохранёнными фильтрами.

## Данные и ежедневное обновление

Источник — [robzilla10001/SwitchPorts](https://github.com/robzilla10001/SwitchPorts). Проект ежедневно в **07:17 Europe/Minsk (04:17 UTC)** получает README, разбирает таблицы, проверяет результат, сохраняет снимок данных в репозитории и публикует сайт через GitHub Pages. GitHub может задерживать запуски. Ручной запуск доступен в Actions → Update catalogue & deploy Pages → Run workflow.

При ошибке источника или изменении формата workflow завершается с ошибкой и оставляет предыдущий опубликованный сайт. JSON содержит `checkedAt`, хеш исходного README, метаданные проектов и историю изменений. На сайте появляется отметка об устаревших данных после 36 часов без успешной синхронизации. Коммит ежедневного снимка также поддерживает активность репозитория для scheduled Actions.

Версии и даты взяты **из каталога источника**, а не из независимой проверки всех релизов. Отметки «архив» и «нет активности» перенесены из источника. «Обновлён недавно» вычисляется по дате проекта за последние 7 дней. Альтернативные порты одного названия сохраняются отдельно. Совместимость означает лишь статус в колонке `Updated for FW 21+?`, а не гарантию запуска на любой версии прошивки.

## Локальный запуск

Нужен Node.js 22+ (в Actions используется 24). Для оптимизации обложек используется Sharp.

```sh
npm ci
npm run sync
# Для обновления звёзд и поиска новых обложек: GITHUB_TOKEN=... npm run enrich
npm run dev
# http://127.0.0.1:4173
```

```sh
npm test
npm run build
# статический сайт в dist/
```

В GitHub Settings → Pages выбран источник **GitHub Actions**. Workflow находится в `.github/workflows/pages.yml`. Используется встроенный `GITHUB_TOKEN`; секреты и отдельный сервер не нужны. Относительные пути поддерживают публикацию в подпапке GitHub Pages.

## Структура

- `public/` — сайт и локальные обложки оригинальных игр.
- `public/data/catalog.json` — последний успешный снимок источника.
- `scripts/parser.mjs` — разбор Markdown, включая альтернативные строки, эмуляторы и HTML-комментарии.
- `scripts/sync.mjs` — загрузка с повторами, валидация и атомарное обновление снимка.
- `scripts/build.mjs` — сборка статических файлов.
- `scripts/enrich.mjs` — ежедневное обновление статистики GitHub и поиск недостающих изображений; существующие изображения сохраняются при ошибках внешних сервисов.
- `scripts/artwork-overrides.mjs` — точные соответствия для неоднозначных названий и объединённых записей.
- `public/data/enrichment.json` — число звёзд, локальные пути картинок и ссылки на их источники.
- `test/` — проверки парсера.

Избранное хранится в `localStorage` текущего браузера и не передаётся на сервер. Счётчиков и аналитики нет. Шрифт Golos Text загружается из Google Fonts; предусмотрен системный запасной шрифт.

Для новых записей без подходящего изображения временно используется типографическая обложка.

Популярность измеряется звёздами репозитория по исходной ссылке проекта: это прозрачный показатель интереса на GitHub, а не число загрузок и не рейтинг качества порта. Отсутствующие значения не подменяются нулями. Для одинакового числа звёзд используется дата обновления, затем название. При сбое GitHub сохраняется последнее известное число звёзд.

Независимый проект, не связанный с Nintendo. Игровые файлы не распространяются. Следуйте инструкциям автора и используйте файлы собственной копии игры, где это необходимо.
